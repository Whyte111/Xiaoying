# 05 复盘

## 最难的三件事

**1. 预算口径只有一个真值**
预算同时涉及方案成本、已付工具费、保存费，还有“保存之后”的状态。任何一处重复计算都会让结果和实际不符。最终收敛到 `guards.check_budget` 一个函数，并用边界测试（8.60 / 8.61 / 8.59）锁住。

**2. “模型在决策”要能被证明**
规则版 Mock 跑得再顺，也只能证明流程通。所以保留真实模型路径，并在 trace 里逐轮记录 `source` 与理由，让“改选方案”这类动作可以被核对，而不是靠叙述。

**3. 状态与幂等**
重复执行、失败续跑、数据变更三件事互相牵扯：指纹要含 provider 与数据哈希，快照要继承成功步骤但不继承重试计数，否则任务会被历史失败永久锁死。

## 学到什么

- 约束检查与决策分离后，换决策器（规则 ↔ 模型）不需要改引擎。
- 幂等不是加个缓存，而是“什么算同一个任务”的定义问题。
- 失败处理的价值不在重试，而在**保留已成功结果并诚实报告缺什么**。
