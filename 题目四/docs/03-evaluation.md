## 已验证（有断言，可复现）

1. **时长可复算**：每个分镜的 `duration_s` 等于"旁白字数 ÷ 平台语速"的复算值，且分镜之和等于总时长。
2. **事实可溯源**：每个分镜的 `fact_refs` 都指向真实存在的素材原文；引用不存在的功能会被判违规。
3. **修正可复现**：同一输入用确定性模型跑两次，得到的脚本逐字节一致。
4. **终止必有界**：步数、工具调用、修正次数三重上限，触顶返回明确状态而非静默截断。
5. **异常不静默**：模型超时/5xx 会重试一次；4xx 立即失败；模型持续输出非法格式抛 `ModelError`；工具报不可满足时立即收敛。
6. **输入不崩**：坏 JSON、字段类型错、BOM、负数/NaN/Infinity 时长，都返回退出码 2 或 `needs_input`，不抛 traceback。
7. **密钥不外泄**：trace 写入前按键名脱敏；模型错误的文案只含状态码。

## 没验证（必须说明）

| 未验证项 | 说明 |
|---|---|
| **真实模型不在自动化里** | 89 项测试全部用 Mock / 脚本化模型。真实模型的产物是**快照**，不是每次 CI 重跑的结果 |
| **真实模型的稳定性** | `02_overrun` 做过 3 次采样，均收敛；`01_normal` 采样多次均 completed，但内容长度在 18–27 秒间浮动 |
| **语义级事实核验** | `fact_refs` 只能证明"引用为真"，不能证明"旁白没有超出所引事实" |
| **模型是否总用 `compress`** | 若模型绕过工具手改旁白，会退化为不可复现，未做大规模采样 |
| **并发** | 同一输入并发跑会互相覆盖 trace（无并发需求） |
| **跨环境** | 仅在 Windows + Python 3.9 验证；其他版本/平台未测 |
| **成本** | 未统计单次运行的耗时与 token |

## 测试本身有效吗

做过一次变异测试：把压缩的内容底线从 50% 改成 99%（等于破坏修正路径），
全套立即出现 **14 失败 + 3 错误**；改回后 **89 全绿**。
说明断言确实盯着行为，而不是"反正能跑绿"。

## 证据的边界

`examples/` 里的 trace 是**某次运行的快照**，不是确定性重放。
`scenarios/test_acceptance.py` 的证据层断言的是"这些快照满足各场景契约"，能防住
"改了代码忘了重跑样例"，**防不住**"今天模型抽风把正常场景跑成未完成"。
如果评审重跑后样例变了、测试变红，那是它在正确报告证据漂移，不是误报。
