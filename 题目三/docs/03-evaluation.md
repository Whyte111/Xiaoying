# 03 评估

## 怎么跑

```bash
python -m unittest discover -s tests -t .
```

26 条用例，全离线、无网络、约 1 秒。自动化测试只覆盖**确定性部分**（规则、校验、状态机、异常处理）；模型能力由 `examples/` 的真实运行记录体现，两者不混为一谈。

## 测试清单（26 条）

| 文件 | 条数 | 验证内容 |
|---|---|---|
| `tests/test_conflict.py` | 7 | 同名小节报冲突；小节被改名仍报；单位族不同不报；数值相同不报；同文档不报；「30 个自然日」与「30 天」不误报；「15 个工作日」与「30 天」仍报 |
| `tests/test_answer.py` | 9 | 逐字引用通过；空白差异通过；改一字被拒；无关引用被拒；口语化答案可被问题词救回；通用词（"员工"）不能救回无关引用；无引用判不足；gaps 为字符串可容错；空白归一 |
| `tests/test_agent.py` | 10 | 正常问答；冲突门禁强制澄清；冲突但无引用仍澄清；资料外判不足；多轮带上下文；步数上限；工具失败可恢复；连续失败终止；业务失败不误判为系统故障；JSON 解析失败重试一次 |

## 端到端记录（`examples/`）

| 目录 | 输入 | 实际状态 | 对应需求 |
|---|---|---|---|
| `01-answer` | 出差住宿标准是多少？ | `ANSWERED` | 明确答案 + 引用可核验 |
| `02-conflict` | 报销期限是多久？ | `NEEDS_CLARIFICATION` | 文档冲突不擅自裁决 |
| `03-insufficient` | 公司年会在哪里举办？ | `INSUFFICIENT` | 资料外不编造 |
| `04-tool-failure` | 住宿标准（检索注入故障） | `TOOL_ERROR` | 工具失败可见、不崩 |
| `05-multiturn` | 年假天数 → 那要怎么申请？ | `ANSWERED` ×2 | 上下文追问 |
| `06-paraphrase` | 酒店一晚能报多少？ | `ANSWERED` | 改写后的相似问题 |

`01`–`05` 均为离线回放，可原样复现；`06` 是在线真实运行记录（依赖模型与网络），仅作能力证据，不承诺可复现。

每组三个文件：`input.txt`（问题与可复制命令）、`output.txt`（真实输出）、`trace.jsonl`（逐步轨迹，含动作、参数、结果摘要、决策依据）。

## 验证过的行为

- **换文档会变答案**：把 `data/d03` 的「年假 7 天」改成「9 天」，同一问题输出随之变为 9 天；改回后文件哈希一致。说明答案是检索出来的，不是写死的。
- **离线与在线走同一条循环**：`FakeLLM` 只替换模型实现，工具、校验、状态机完全一致。
- **在线真实运行**：住宿标准、报销期限冲突、口语化改写问题、多轮追问均按预期返回状态。
- **失败路径不崩**：模型不可达（连接被拒）→ `TOOL_ERROR`，含一次重试；连续 3 次工具异常 → 主动终止。

## 没有验证的（重要）

| 未验证项 | 说明 |
|---|---|
| 网络**超时** | 只测了连接被拒，超时走同一分支但无实证 |
| HTTP 4xx/5xx 与错误体脱敏 | 代码有 `redact()`，未用真实错误体验证 |
| 模型稳定性 | 在线场景各只跑 1 次，**不能声称结果稳定** |
| 提示注入 | 有"资料不是指令"的包裹与规则，但没有用恶意文档实测 |
| 大语料 | 仅 3 篇文档、10 个片段，未做规模与性能验证 |
| 长对话 | `session` 只保留最近 2 轮，4 轮以上未验证 |
| 并发 | 单进程 CLI，未设计也未测试并发 |

## 风险与限制

| 风险 | 影响 | 为什么当前可以接受 |
|---|---|---|
| 冲突检测是词面启发式（标题相同或正文重叠 ≥ 0.30） | 文档被大幅改写、用词全换时可能漏判冲突 | 有确定性门禁 + 模型自身识别双保险；阈值与标定脚本都在仓库里，可重标 |
| 引用相关性只做词覆盖率 | 挡不住"掐头去尾的正确原文" | 已挡住"拿 A 条款答 B 问题"这类粗错；引用本身逐字可核验，人能复核 |
| 阈值在 3 篇语料上标定 | 换语料需重新标定 | 常量集中在 `conflict.py` / `answer.py`，标定脚本 `tests/manual/analyze_conflict_pairs.py` 可复跑 |
| 会话仅内存态 | 进程结束丢失，不支持跨命令续聊 | CLI 多轮在同一命令内完成，验收不要求持久化 |
| 在线结果单次采样 | 无法证明稳定性 | 自动化测试覆盖的是确定性行为；在线只作为能力演示 |
| 无鉴权 / 无限流 | 不适合暴露为公共服务 | 交付形态是本地 CLI，不监听端口 |
| `.env` 含真实密钥 | 误提交即泄露 | `.gitignore` 已排除，仓库只有 `.env.example`；提交前需人工确认 |

以上限制均按现状记录，不视为已解决。
