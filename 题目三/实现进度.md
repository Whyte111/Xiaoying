## 2. 验证方式（PowerShell 需 UTF-8 代码页）

```powershell
chcp 65001 | Out-Null; $env:PYTHONUTF8='1'

# 1 正常（离线）
python -m src.cli ask "出差住宿标准是多少？" --offline --script tests/fixtures/script_happy.json
# 2 冲突门禁（离线，模型故意只引 D02）
python -m src.cli ask "报销期限是多久？" --offline --script tests/fixtures/script_conflict.json
# 3 冲突（在线，模型自主 ask_user）
python -m src.cli ask "报销期限是多久？" --trace-out runs/t7.jsonl
# 4 资料外（在线）
python -m src.cli ask "公司年会在哪里举办？" --trace-out runs/t8.jsonl
# 5 多轮追问（离线）
python -m src.cli ask "入职满3年不满5年的员工年假有几天？" "那要怎么申请？" --offline --script tests/fixtures/script_multiturn.json
# 6 多轮追问（在线）
python -m src.cli ask "入职满3年不满5年的员工年假有几天？" "那要是今年没休完呢？" --trace-out runs/t10.jsonl
# 7 步数上限
python -m src.cli ask "出差住宿标准是多少？" --steps 1
# 8 工具失败可恢复（离线）
python -m src.cli ask "出差住宿标准是多少？" --offline --script tests/fixtures/script_fault_recover.json --fault search --fail-times 1
# 9 工具连续失败（离线）
python -m src.cli ask "出差住宿标准是多少？" --offline --script tests/fixtures/script_fault_dead.json --fault search --fail-times 9
# 10 工具失败可恢复（在线，真实模型）
python -m src.cli ask "出差住宿标准是多少？" --fault search --fail-times 1 --trace-out runs/t13.jsonl
```

实测结果：

| # | 用例 | 期望 | 实际 |
|---|---|---|---|
| 1 | 住宿标准（离线） | ANSWERED + 引用 | ✅ |
| 2 | 冲突 + 模型单选 D02 | NEEDS_CLARIFICATION + 双方引用 | ✅ 门禁拦截 |
| 3 | 冲突（在线） | NEEDS_CLARIFICATION | ✅ 模型自主 ask_user |
| 4 | 资料外问题 | INSUFFICIENT + 缺口说明 | ✅ |
| 5 | 两轮追问（离线） | 两轮均 ANSWERED，trace 带 turn | ✅ |
| 6 | 两轮追问（在线） | 第二轮检索词含上下文 | ✅ 查询改写为「年假 未休完 跨年 结转…」 |
| 7 | `--steps 1` | STEP_LIMIT | ✅ |
| 8 | 检索失败 1 次后重试（离线） | ANSWERED，trace 含 `ok=false` 后转 `ok=true` | ✅ |
| 9 | 连续 3 次失败 | TOOL_ERROR，进程不崩 | ✅ |
| 10 | 故障注入 + 真实模型 | ANSWERED，模型换词检索两次后作答 | ✅ |

多轮"上下文是否真被使用"的判据：`runs/t10.jsonl` 第 2 轮 `search` 的 query 是
`年假 未休完 跨年 结转 清零 补偿`，而用户原话是"那要是今年没休完呢"——"年假"这个词只可能来自历史。

## 3. 当前能力边界

1. **无 query 改写专项**："改写后的相似问题"目前依赖模型自发改写检索词，未单独做 query expansion 环节。
2. **无 `tests/`**：仍靠手工命令验证。
3. **无 README / docs / examples 正式材料**。
4. **会话不持久化**：进程结束即丢；跨命令续聊不支持。
5. **冲突检测是启发式的**：只认「小节标题去序号后相同」+ 数值不同；标题不同但内容冲突会漏报。
6. **冲突提示按问题相关性过滤**：冲突主题词与用户问题无交集时不提示，跨主题的真实冲突可能因此漏报。

## 4. 相对系统骨架的偏差（显式记录）

| 骨架承诺 | 实际 | 原因 |
|---|---|---|
| Pydantic 校验 | 手写 dict 校验 + `_as_list` 兜底 | 环境无 pydantic，零依赖 |
| `openai` SDK | stdlib `urllib` | 环境无 openai 包 |
| jieba + 自定义词典 | jieba（无自定义词典） | 编号靠 alnum token 兜底 |
| `chat` 交互子命令 | `ask` 传多个问题即为多轮 | 规避 Windows stdin 编码问题 |
| 引用"逐字"校验 | 去空白后逐字包含 | 待确认口径 |
| Session 持久化 | 内存态 | 最小实现 |
